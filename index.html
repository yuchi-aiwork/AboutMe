Core Engineering Projects

代表性工程實績與核心專案

PROJECT 01

VR 系統級多媒體管線與 RTMP 直播系統 (0 到 1 自主研發)

Android MediaCodec RTMP 串流協定 Wi-Fi Display 投屏
專案挑戰與目標

VR 頭顯在運行高負載 3D 內容時，若同時執行螢幕錄製或直播推流，極易引發 CPU/GPU 資源爭搶，面臨掉幀、記憶體突波與系統過熱等多重挑戰。

架構設計與實作

從 0 到 1 深度整合 Android MediaCodec 硬體編碼與 RTMP 協定；重構 Surface 生命週期與雙緩衝管線，將繁重編碼工作卸載至專屬硬體晶片，實現非同步高效編解碼。

交付成果與價值

成功實現 VR 頭顯低延遲 YouTube 直播、原生錄影與 Miracast 無線投屏，確保前台 3D 渲染與背景多媒體管線互不干擾、長期穩定運行。

PROJECT 02

WaveXR / OpenXR 跨平台 Unity SDK 架構與硬體整合

商業級 XR SDK 硬體抽象轉接層 跨平台架構擴充
專案挑戰與目標

面對新世代 XR 控制器按鍵配置、空間定位與周邊硬體快速迭代，既有企業客戶 SDK 存在相容性碎片化與事件分發維護成本高的瓶頸。

架構設計與實作

主導 WaveXR 與 OpenXR 雙版本 Unity SDK 介面擴充；設計解耦的硬體事件抽象分發層與轉接機制，支援外設熱插拔與即時鍵位映射，並建立健全的邊界測試防護。

交付成果與價值

快速打通多家企業客戶的新硬體周邊對接，顯著縮減新裝置適配週期，提供企業開發者高可靠度與長期向下相容的 SDK 整合體驗。

PROJECT 03

VIVE Sync 企業級虛擬協作效能調優

Unity 效能調優 記憶體架構重構 遮擋剔除 (Occlusion Culling)
專案挑戰與目標

在 VIVE Sync 跨國多人虛擬會議應用中，用戶拍攝高解析快照時容易引發瞬時卡頓與雙倍 RenderTexture 記憶體峰值，影響商務協作流暢度。

架構設計與實作

透過 Unity Profiler、Memory Profiler 與 Android Logcat 定位 CPU-GPU 傳輸與記憶體拷貝瓶頸；導入 ASTC 紋理壓縮規範、動態降採樣機制與視野遮擋剔除 (Occlusion Culling)。

交付成果與價值

全面消除快照時的卡頓現象並顯著抑制記憶體峰值，徹底解決獨立 VR 一體機在長時間多人群聚會議中的掉幀與穩定性問題。
